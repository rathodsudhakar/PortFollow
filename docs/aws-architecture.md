## 2. Infrastructure Components

### 2.1 S3 Storage Origin
- Production assets generated by Vite (`dist/index.html`, JavaScript bundles, CSS chunks, favicon, and resume documents) are stored in an encrypted, Amazon S3 static bucket managed entirely by AWS Amplify.
- Public read access is strictly mediated through CloudFront Origin Access Identity (OAI) / Origin Access Control (OAC).

### 2.2 AWS CloudFront Global Edge Network
- Low-latency delivery across worldwide AWS Edge Locations.
- Dynamic caching headers configured for static hashed assets (`assets/*` cached for 1 year with immutable tag; `index.html` cached with zero-delay revalidation).

### 2.3 Automated TLS / SSL Certificate (ACM)
- Complimentary, automatically renewed SSL certificates issued via AWS Certificate Manager (ACM).
- Enforces HTTP to HTTPS 301 redirection.

## 3. Continuous Integration & Deployment Pipeline (`amplify.yml`)

The root `amplify.yml` configuration specifies the build lifecycle:

```yaml
version: 1
frontend:
  phases:
    preBuild:
      commands:
        - npm ci
    build:
      commands:
        - npm run build
  artifacts:
    baseDirectory: dist
    files:
      - '**/*'
  cache:
    paths:
      - node_modules/**/*
```

### Pipeline Steps:
1. **Provision:** AWS Amplify spins up an isolated Amazon Linux build container with Node.js and npm pre-installed.
2. **Pre-build:** Executes `npm ci` leveraging cached dependencies from previous runs for rapid install times.
3. **Build:** Runs `npm run build` which triggers TypeScript compilation check (`tsc -b`) followed by Vite production bundling into `dist/`.
4. **Deploy:** Artifacts in `dist/` are synchronized to the S3 origin, and a CloudFront edge cache invalidation is dispatched.

## 4. Step-by-Step Setup Guide on AWS Amplify

### Step 1: Push Code to GitHub
Ensure the PortFollow project is committed to a GitHub repository:
```bash
git init
git add .
git commit -m "feat: complete PortFollow DevOS portfolio application"
git branch -M main
git remote add origin https://github.com/rathodsudhakar/portfollow.git
git push -u origin main
```

### Step 2: Connect Repository in AWS Console
1. Log in to the [AWS Management Console](https://console.aws.amazon.com/).
2. Navigate to **AWS Amplify**.
3. Click **Host a web app**.
4. Choose **GitHub** as the source repository and authorize AWS Amplify.
5. Select the repository (`portfollow`) and the branch (`main`).

### Step 3: Configure Build Settings
1. Amplify will automatically detect the presence of `amplify.yml`.
2. Confirm the build output directory is set to `dist`.
3. Click **Next**, review the configuration, and click **Save and deploy**.

### Step 4: Single-Page Application (SPA) Rewrite Rule
To ensure direct sub-routes or browser refreshes route to `index.html`:
1. In the Amplify console, go to **App settings** > **Rewrites and redirects**.
2. Verify the default rule:
   - **Source address:** `</^[^.]+$|\.(?!(css|gif|ico|jpg|js|png|txt|svg|woff|woff2|ttf|map|json)$)([^.]+$)/>`
   - **Target address:** `/index.html`
   - **Type:** `200 (Rewrite)`

### Step 5: Custom Domain Configuration (Optional)
1. In the Amplify console, select **Domain management** > **Add domain**.
2. Enter your custom domain (e.g., `sudhakar.dev` or `portfollow.dev`).
3. If using Amazon Route 53, DNS records are created automatically. If using an external registrar (Cloudflare, Namecheap, GoDaddy), create the required CNAME and verification TXT records.
4. Amplify provisions and attaches the SSL certificate automatically.
